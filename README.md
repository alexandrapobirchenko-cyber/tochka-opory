# Точка опоры

Веб-приложение для самопомощи в трудных ситуациях на основе психосоматического и коучингового подхода (методическая основа — работы М. Е. Сандомирского).

## Файлы
- `index.html` — всё приложение (разметка, стили, логика).
- `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png` — для установки на телефон.
- `CHANGELOG.md` — журнал изменений.

## Как обновлять
1. Получить новую версию `index.html`.
2. В репозитории на GitHub: Add file → Upload files → перетащить файл → Commit changes.
3. Через 1–2 минуты сайт обновится. Данные пользователей при этом сохраняются.
4. Дописать строку в `CHANGELOG.md` и поднять `APP_VERSION` в `index.html`.

## Данные
Записи хранятся в браузере пользователя (localStorage). Если очистить данные браузера или открыть сайт на другом устройстве, записей там не будет. Перед очисткой — «Профиль и данные» → «Скачать всё (JSON)».
